# Security

Report sensitive findings privately through GitHub private vulnerability reporting if enabled, or contact the repository owner privately through their GitHub profile. Do not publish passwords, API keys, personal data or exploit payloads in public issues or pull requests.

Never commit live credentials. Use deployment environment variables or the hosting secret store; use empty placeholders in example files. Revoke or rotate an exposed credential at its provider even after deleting it from the current tree. Removing source text does not remove historical copies.

Changes to application behavior and dependencies require review and relevant checks before production deployment. This repository does not claim an active supported-release policy solely because this file exists.
